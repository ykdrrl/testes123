Petunjuk Mengubah / Menambah Foto Kamu

1. Upload foto kamu ke platform penyedia gambar gratis seperti Imgur.com atau Postimages.org.

2. Ambil **Direct Link** foto tersebut (biasanya berakhiran .jpg, .png, atau .webp).

3. Buka file kodingan ini (index.html) di GitHub atau text editor, lalu cari bagian array memoryData di skrip bawah.

4. Tambahkan atau ubah URL foto, tanggal, serta deskripsinya sesuai keinginanmu lalu Simpan/Commit!
